# FoodHub Data Analysis-
'Analyzed 1,898 food delivery orders for FoodHub, a food aggregator platform, using Python (pandas, Seaborn) to uncover patterns in cuisine preference, delivery performance, and customer rating behavior. Identified a significant gap in rating completion (39% of orders unrated) and a weekday/weekend delivery-time disparity, translating findings into recommendations for improving customer engagement and operational efficiency.'
